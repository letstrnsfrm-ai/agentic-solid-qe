# CI/CD Pipeline Templates & Regression Tagging Guide

Use these patterns when executing `04-ci-pipeline` to operationalize SOLID Playwright suites in enterprise CI/CD pipelines.

---

## 1. Regression Tagging Convention (`tests/*.spec.ts`)

Every automated spec generated by `02-solid-architect` or curated by `04-ci-pipeline` should carry structured tags in its `test.describe` or `test` title so CI/CD pipelines can slice execution by risk tier:

| Tag | Target Execution Gate | Typical Scenarios | CLI Filter Command |
| :--- | :--- | :--- | :--- |
| `@p0` / `@smoke` | Every PR & Deployment Gate (< 3 min) | Core multi-page Golden Path (`happy-path-baseline`) | `npx playwright test --grep "@smoke\|@p0"` |
| `@p1` | Merge to `main` / Pre-Release Gate | Persona boundaries (`multi-persona-auth`) & form validation (`boundary-analysis`) | `npx playwright test --grep "@p1"` |
| `@p2` / `@regression` | Scheduled Nightly / Full Regression | State interruption (`reload`/`go-back`) & API chaos (`chaos-network-500`) | `npx playwright test` |

---

## 2. Environment Variables & Secret Wiring

Never commit production/staging secrets in `src/data/*.builder.ts`. Always wire environment variables in CI/CD:
- `BASE_URL`: Target deployed environment URL (e.g., `https://staging.example.com`)
- `TEST_USERNAME` / `TEST_PASSWORD`: Primary persona credentials consumed by `src/data/user.builder.ts`

---

## 3. GitHub Actions Sharded Pipeline Blueprint (`.github/workflows/playwright-ci.yml`)

Ensure the CI workflow executes deterministic static gates before launching browser shards:
1. **Static Architecture & Tape Gate:**
   ```bash
   npm run typecheck
   npm run audit:solid
   npm run validate:tapes
   ```
2. **Sharded Playwright Execution:**
   ```bash
   npx playwright test --project=chromium --shard=${{ matrix.shard }}
   ```
3. **Failure Forensics Artifact Upload:**
   Upload `playwright-report/` and `test-results/` (traces and failure screenshots) with `if: always()` so `03-drift-healer` or engineers can inspect failures immediately.
